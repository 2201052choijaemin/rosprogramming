# Middleware, DDS 및 ROS2 통신 기술 정리

## 1. Middleware란?

미들웨어(Middleware)는 **운영체제와 애플리케이션 사이에서 서로 다른 프로그램이나 시스템이 원활하게 통신할 수 있도록 지원하는 소프트웨어**이다.
분산 시스템에서는 데이터 전달, 통신 관리, 메시지 처리 등의 기능을 제공하여 개발자가 복잡한 네트워크 통신을 직접 구현하지 않아도 되도록 도와준다.

---

## 2. Distributed Computing이란?

분산컴퓨팅(Distributed Computing)은 **여러 대의 컴퓨터가 네트워크를 통해 연결되어 하나의 시스템처럼 작업을 수행하는 방식**이다.

각 컴퓨터가 작업을 나누어 처리하기 때문에 성능을 높일 수 있으며, 일부 시스템에 문제가 발생하더라도 전체 시스템의 안정성을 높일 수 있다.

**주요 특징**

* 여러 컴퓨터가 작업을 분산하여 처리
* 네트워크를 통한 데이터 통신
* 확장성이 좋음
* 병렬 처리 및 시스템 안정성 향상

---

## 3. 네트워크 통신 기술

네트워크 통신은 **서로 다른 장치들이 네트워크를 통해 데이터를 주고받는 기술**이다.

대표적인 통신 방식으로 TCP/IP, UDP, HTTP 등이 있으며, 목적에 따라 신뢰성, 속도, 실시간성 등을 고려하여 적절한 방식을 선택한다.

* **TCP**: 데이터 전달의 신뢰성이 높지만 상대적으로 속도가 느릴 수 있음
* **UDP**: 빠른 데이터 전송이 가능하지만 데이터 전달의 신뢰성을 직접 보장하지 않음
* **HTTP**: 웹 기반의 데이터 통신에 주로 사용

---

## 4. RTPS (Real-Time Publish-Subscribe)

RTPS는 **실시간 Publish-Subscribe 방식의 데이터 통신을 위한 프로토콜**이다.

Publisher가 데이터를 발행하면 해당 데이터를 필요로 하는 Subscriber가 전달받는 구조이다.
ROS2에서 사용하는 DDS의 통신 기반으로 활용되며, 실시간성과 분산 환경에서의 통신을 지원한다.

**구조**

```text
Publisher → Topic → Subscriber
```

Publisher와 Subscriber가 서로 직접 연결되지 않아 시스템의 확장성이 높다는 장점이 있다.

---

## 5. DDS의 Dynamic Discovery

DDS의 Dynamic Discovery는 **네트워크에 존재하는 Publisher와 Subscriber를 자동으로 발견하고 서로 통신할 수 있도록 연결 정보를 교환하는 기능**이다.

별도의 중앙 서버 없이 각 노드가 자신의 존재와 제공하는 데이터를 알리고, 필요한 데이터를 가진 상대방을 자동으로 찾을 수 있다.

```text
Node A ── Discovery ── Node B
   │                     │
Publisher              Subscriber
```

따라서 새로운 노드가 추가되거나 제거되어도 동적으로 통신 구성을 변경할 수 있다.

---

## 6. ROS1과 ROS2의 통신 방식 차이

### ROS1

ROS1은 기본적으로 **ROS Master를 중심으로 노드들의 연결 정보를 관리**한다.

```text
Node A ──┐
         ├── ROS Master
Node B ──┘
```

노드가 통신하기 위해 Master를 통해 상대 노드의 정보를 확인하는 방식이다.

### ROS2

ROS2는 **DDS를 기반으로 통신하며 DDS의 Discovery 기능을 사용**한다.

```text
Node A ←── DDS Discovery ──→ Node B
```

중앙 Master에 의존하지 않고 노드들이 서로를 자동으로 발견할 수 있어 분산 시스템과 실시간 시스템에 더 적합하다.

---

## 7. ROS2에서 DDS를 도입한 이유

ROS2가 DDS를 도입한 주요 이유는 **분산 환경, 실시간 통신, 안정적인 데이터 전달 및 확장성을 지원하기 위해서**이다.

DDS를 사용하면 다음과 같은 장점이 있다.

* 중앙 서버 없이 노드 자동 검색 가능
* 다양한 QoS(Quality of Service) 설정 지원
* 실시간 통신 지원
* 신뢰성, 데이터 전달 방식 등을 세밀하게 설정 가능
* 여러 장치와 네트워크 환경에서 확장성이 높음

따라서 ROS2는 DDS를 활용하여 로봇 시스템에 필요한 다양한 통신 요구사항을 지원한다.

---

## 8. MQTT와 DDS의 차이

MQTT와 DDS는 모두 Publish-Subscribe 방식의 통신 기술이지만 **통신 구조와 사용 목적에 차이**가 있다.

| 구분        | MQTT          | DDS               |
| --------- | ------------- | ----------------- |
| 통신 구조     | Broker 중심     | 분산형               |
| Discovery | Broker를 통해 관리 | Dynamic Discovery |
| 주요 목적     | IoT, 메시지 전달   | 실시간·분산 시스템        |
| QoS       | 지원            | 다양한 QoS 지원        |
| 실시간성      | 상대적으로 제한적     | 높은 실시간성 지원        |
| 대표 활용     | IoT, 센서, 클라우드 | 로봇, 자율주행, 산업 시스템  |

**MQTT**는 가볍고 구조가 단순하여 IoT 환경에서 많이 사용되고, **DDS**는 실시간성과 안정적인 데이터 분산이 중요한 로봇 및 산업 시스템에서 많이 사용된다.

---

## 정리

ROS2는 **DDS와 RTPS를 기반으로 한 분산 통신 구조**를 사용한다.
ROS1의 ROS Master 중심 구조와 달리 ROS2는 DDS의 Dynamic Discovery를 이용하여 노드 간 통신을 자동으로 구성할 수 있다.

```text
ROS2
 └── DDS
      └── RTPS
           └── Publish / Subscribe
                ├── Publisher
                └── Subscriber
```

이를 통해 ROS2는 **분산 환경, 실시간 통신, QoS 설정, 확장성** 등의 장점을 갖는다.
