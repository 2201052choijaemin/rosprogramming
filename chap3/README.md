1. ROS1과 ROS2의 통신방식의 관점에서 차이를 설명하라.
-ROS1은 주로 ROS Master를 이용하여 노드들이 서로 연결되고, TCPROS/UDPROS를 통해 데이터를 주고받는다.
-ROS2는 ROS Master에 의존하지 않고, **DDS(Data Distribution Service)**를 이용하여 노드들이 서로 통신한다.

 2. ROS1의 통신 미들웨어인 TCPROS와 ROS2의 통신 미들웨어인 DDS의 차이를 설명하라.
-TCPROS:TCP/IP를 기반으로 노드 간 데이터를 전달
-DDS: 네트워크에서 데이터를 자동으로 발견하고 통신

3. 실시간 시스템(real time system)의 정의를 조사하라.
-정해진 시간 안에 반드시 작업을 처리해야 하는 시스템

4. GPL라이선스와 Apache 2.0 라이선스의 차이를 설명하라.
GPL: 소프트웨어를 수정하여 배포할 경우, 일반적으로 수정된 소스코드도 GPL 조건으로 공개해야 하는 강한 카피레프트 라이선스이다.
Apache 2.0:소프트웨어를 자유롭게 사용·수정·배포할 수 있으며, 수정한 코드를 공개할 의무가 없는 허용적 라이선스이다.

5. 멀티 프로세싱을 설명하라.
-하나의 컴퓨터에서 여러 개의 프로세스를 동시에 실행하는 방식

6. 분산 컴퓨팅을 설명하라.
-여러 대의 컴퓨터가 네트워크로 연결되어 하나의 시스템처럼 작업을 수행하는 방식

7. 네트워크 통신을 설명하라.
-서로 다른 컴퓨터나 장치가 네트워크를 통해 데이터를 주고받는 것
