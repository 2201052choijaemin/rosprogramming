ROS 주요 개념 정리
1. 패키지 (Package)

ROS에서 프로그램을 구성하는 가장 기본적인 단위이다.
노드, 메시지, 서비스, 액션, 설정 파일, 실행 파일 등을 하나의 단위로 묶어서 관리한다.

2. 노드 (Node)

ROS에서 실제로 실행되는 프로그램의 단위이다.
하나의 노드는 특정 기능을 수행하며, 다른 노드와 메시지, 서비스, 액션 등을 통해 통신한다.

3. 메시지 (Message)

노드 간에 데이터를 주고받기 위해 사용하는 데이터 구조이다.
예를 들어 센서 값, 위치, 속도 등의 데이터를 정해진 형식으로 표현한다.

4. 메시지 통신 (Message Communication)

노드 간에 메시지를 주고받는 통신 방식이다.
대표적으로 토픽(Topic) 을 이용한 비동기 통신이 있으며, 발행자(Publisher)가 데이터를 보내고 구독자(Subscriber)가 데이터를 받는다.

5. 토픽 (Topic)

ROS에서 노드 간에 메시지를 전달하기 위한 통신 채널이다.
하나의 노드가 데이터를 발행(Publish)하고, 다른 노드가 이를 구독(Subscribe)할 수 있다.
주로 센서 데이터나 지속적으로 발생하는 데이터를 전달할 때 사용한다.

6. 서비스 (Service)

요청(Request)과 응답(Response) 방식으로 노드 간 통신을 수행하는 기능이다.
특정 작업을 요청하고 그 결과를 한 번 응답받을 때 사용한다.

7. 액션 (Action)

시간이 오래 걸리거나 진행 상태를 확인해야 하는 작업을 수행하기 위한 통신 방식이다.
목표(Goal)를 전달하면 작업이 수행되고, 진행 상태(Feedback)와 최종 결과(Result)를 받을 수 있다.
필요한 경우 작업을 중간에 취소할 수도 있다.

8. 파라미터 (Parameter)

노드의 동작을 설정하기 위해 사용하는 값이다.
예를 들어 속도, 센서 설정값, 경로 등의 설정 정보를 저장하고 실행 중인 노드가 이를 사용할 수 있다.

요약
개념	설명
패키지	ROS 프로그램을 구성하고 관리하는 단위
노드	실제로 실행되는 프로그램 단위
메시지	노드 간 전달되는 데이터의 형식
메시지 통신	노드 간 데이터를 주고받는 통신 방식
토픽	메시지를 전달하는 통신 채널
서비스	요청과 응답으로 수행되는 통신 방식
액션	진행 상태와 취소가 가능한 장시간 작업 통신 방식
파라미터	노드의 동작을 설정하는 값
