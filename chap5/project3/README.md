토픽의 전송률(average rate) : 초당 전송 횟수(Hz), 주기 = 1/초당 전 송 횟수(sec)
min, max -> 토픽 통신 주기(sec)의 최소, 최대값
std dev : 토픽 통신 주기의 표준편차(sec)
window : 전송률과 주기를 계산할 때 사용하는 최근 통신 데이터의 개수
